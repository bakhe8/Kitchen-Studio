# Finish Studio Implementation Plan

**Goal:** اختيار خامات وألوان ومقابض الوحدات مباشرة من الرسم، بمعاينة فورية تحفظ ارتباط الأصناف بالكتالوج والحصر والتصنيع.

**Architecture:** توسيع مسار `mountFinishDesk` القائم. بيانات التشطيب تبقى على مستوى الوحدة ونوع الجزء؛ رقم الدرفة/الدرج سياق تحديد ولا يعني تخصيص نسخة منفردة. معاملة معاينة واحدة قبل كل حفظ صريح، مع إلغاء وتراجع محلي ثم تاريخ المشروع. المنظور القائم يعرض ألوان الأسطح ومراكز تثبيت المقابض الفعلية.

**Decisions:** الأصناف المنشورة فقط؛ لا لوحة ألوان مستقلة عن SKU. منع المشكلات التصنيعية الجديدة قبل حفظ المعاينة، مع استمرار بوابة اعتماد الهيكل. عرض سعر المواد وإجمالي العرض بمسميين منفصلين، وعدم حساب فرق عند غياب الأسعار. التحديد أو الانتقال إلى جزء آخر يلغي معاينة غير محفوظة مع بيان ذلك؛ مغادرة المسار يحميها حارس العمل غير المحفوظ.

## Work

- [x] مراجعة موحدة للمعاينة والأسعار والمخزون، مع اختبارات فعلية للنموذج.
- [x] قائمة وحدات، منظور وواجهة، بطاقات كتالوج وأدوات سياقية، تطبيق/إلغاء ومعاينة فورية.
- [x] ربط الحفظ والتراجع والصلاحيات وتغير المشروع واستعادة الأخطاء.
- [x] اختبارات المسار السابقة والجديدة، تجميع، ورحلة متصفح كاملة مع دليل محفوظ؛ الحزمة النهائية 211/211.
- [x] توثيق FSM ودورة التفاعل ونتائج الاختبارات وحدودها.
