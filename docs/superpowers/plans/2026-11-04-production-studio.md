# Production Studio Implementation Plan

**Goal:** مراجعة القص والتجميع من قطع المشروع الفعلية وربطها بالوحدات والخامات وعمليات التشغيل، مع معاينة مباشرة وحفظ وتراجع واعتماد الورشة عبر الصلاحيات القائمة.

**Design:** مسار `production` داخل بوابة المصنع. فهرس الوحدات، رسم القطعة/توزيع الخام/مراجعة التجميع، ومفتش سياقي لعملية الوصفة. الأبعاد والكميات مشتقة من المشروع؛ تعديل العملية يبين جميع الوحدات المتأثرة بالوصفة المشتركة. تعريفات الماكينات والكتالوج وسجل التصدير تبقى متاحة من مصادرها الحالية.

**State:** `saved → preview → saving → saved`؛ الإدخال غير الصالح `invalid` وتغير المصدر `stale`. حفظ صريح واحد، إلغاء وتراجع محلي قبل تاريخ المشروع، حماية للمغادرة والتصدير والاعتماد. لا تعديل صامت للقطع المشتقة ولا اعتماد تلقائي.

**Authority:** المصنع والمالك يحرران سجل المصنع ويعتمدانه؛ إطلاق النسخة من مسار اعتماد المالك الحالي. التنفيذ السحابي سجل أحداث مرتبط بإيصال ثابت، ولا يعكسه تراجع المشروع.

- [x] مساحة المراجعة والرسوم والأدوات السياقية وربط المصادر.
- [x] الحفظ والتراجع والصلاحيات واعتماد المصنع وبوابات إطلاق التصنيع.
- [x] اختبارات رحلة متكاملة وحالات الخطأ وتغير المصدر.
- [x] فحص المتصفح والتصدير والحزمة وتوثيق الدليل والحدود.
