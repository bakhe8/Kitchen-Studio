# Quote Studio Implementation Plan

**Goal:** مراجعة الحصر وعرض السعر من الوحدات والخامات المستخدمة فعليًا، مع معاينة تكلفة فورية وحفظ صريح وتراجع واعتماد عميل عبر بواباته القائمة.

**Architecture:** مساحة جديدة داخل مسار الحصر، تستعمل `buildFactoryQuote` ومفاتيح الاعتماد الحالية. يبقى سجل القص والمشتريات والتصدير مفصلًا قابلًا للفتح. ربط ثنائي الاتجاه بين الوحدة والصنف وقطع الوصفة، دون اختراع حصص تكلفة للوحدات من خام مشترك.

**Authority:** تعديل السعر وشروط البيع من مساحة الحصر متاح للمالك فقط؛ تمر الكتابة عبر `cleanCatalog` و`reconcileWorkshopCatalogs` وحفظ المشروع وسياسة الكتابة القائمة. لا يمنح تعديل السعر اعتمادًا تلقائيًا للمتجر أو شروط البيع أو العميل.

**Interaction:** تحديد وحدة/صنف/خدمة ← إدخال دقيق ← معاينة محلية متعددة البنود ← حفظ واحد صريح أو إلغاء. تراجع محلي قبل تاريخ المشروع. المعاينة غير الصالحة تمنع الحفظ والتصدير والاعتماد وتبقى قابلة للتصحيح. تغيير التحديد يحتفظ بالمدخلات؛ المغادرة تحمي المسودة. عرض العميل التجريبي موسوم غير محفوظ.
