# Designer Studio Implementation Plan

**Goal:** دمج مساحة توزيع للمصمم مبنية على قياسات دفتر الموقع، مع تفاعل مباشر ومعاينة وتراجع وحفظ حقيقي.

**Architecture:** توسيع `mountWholePlan` و`proposalScene` فوق نموذج الصف والمشروع القائم. ترتيب الوحدات عملية ذرية تشمل CAD ووصفة المصنع؛ المعاينة لا تحفظ المشروع. واجهة مرافقة تعيد تنظيم أدوات المصمم الفعلية وتحافظ على هويات الجدران والوحدات.

**Tech Stack:** JavaScript ES modules، SVG، CSS RTL، فحوص Node والمتصفح المحلي.

**Spec:** طلب المستخدم في هذه المحادثة ومعمارية OOUX السابقة؛ وثيقة السلوك النهائية في `docs/kitchen-studio/designer-studio-integration.md`.

## القرارات

اخترنا هندسيًا توسيع مسار المصمم القائم: إعادة بناء محرر موازٍ ستفصل وصفة المصنع عن الرسم، وتغيير الشكل وحده لا يضيف التحكم المباشر المطلوب. لا تغيير لقواعد تحرير المجلى والأجهزة أو الاعتماد والتصنيع. الجدار القابل للتصميم يظل يحتاج سلسلة محفوظة متطابقة وحدّ نهاية/ركن؛ التوثيق الميداني حالة مستقلة.

التفاعل يبدأ بفهم الجدار والصف والوحدة؛ التحديد يفتح أدوات الوحدة، والكتابة/السحب تعرض النتيجة، والتطبيق يثبت مسودة، والحفظ يكتب المشروع. التراجع المحلي للمسودة منفصل منطقيًا عن سجل المشروع المحفوظ ويظهر ضمن شريط واحد بوصف واضح.

## التنفيذ والفحوص

- [x] عملية ترتيب داخل الجزء المتصل من صف المصنع، تحفظ العروض والهويات ومواضع الأجهزة المقيدة؛ اختبارات قبل التنفيذ للحدود والفواصل والتثبيت والتزامن والحفظ والتراجع.
- [x] مساحة RTL: الجدران المقاسة والوحدات، الرسم، خصائص العنصر وأساس القياس، HUD قرب العنصر؛ إبقاء الخيارات والبدائل والتقارير ظاهرة عند الحاجة.
- [x] معاينة حية للكتابة، إلغاء واسترجاع الرقم السابق، أسهم وسحب عناوين الحقول بخطوة المصنع، وحماية النص غير المطبق من التحديد والتنقل والحفظ.
- [x] مقبض نقل الوحدة مع اتجاه الجدار والالتقاط إلى مواضع الصف؛ إلغاء المؤشر/Escape يعيد الرسم السابق؛ رفض التحريك غير الصالح دون تعديل المصدر.
- [x] ربط تاريخ المشروع عبر واجهة الورشة مع حارس المسودة والصلاحيات؛ إضافة إعادة للمسودة، وإعادة تشغيل وصفة المسودة بعد التحميل تشمل عمليات الترتيب.
- [x] فحوص آلية كاملة، تجميع المتصفح، ورحلة من دفتر الموقع إلى التوليد والتوزيع والقيود والحفظ والتراجع وإعادة الفتح، مع تقرير وحدود الدليل.

## نقاط المراجعة

الهوية عند تغيير الوحدة أثناء إدخال رقم؛ تجاوز عنصر مثبت أو فتحة؛ فقد التقاط المؤشر؛ تغيير المشروع أثناء المعاينة؛ فشل الحفظ؛ عدم إعلان التوثيق/الإفراج بسبب مجرد نجاح توزيع؛ حفظ المسودة وإعادتها بعد تغيير ترتيب الوحدات؛ استمرار لوحة المفاتيح والتركيز بعد التراجع.
