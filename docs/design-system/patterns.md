# Measured Workshop patterns

## Local state and recovery

Each feature styles the status actually emitted by its controller. Dirty/preview/pending/saving conditions use attention and a dashed edge; invalid/error/stale/blocked conditions use danger and a double boundary. Saved/ready/confirmed/closed conditions use completion with an existing label and double edge. Neutral connection text remains information when the controller has no distinct state attribute. Do not reinterpret arbitrary message strings or add domain decisions to CSS.

Saved projects retain open, prepare-delete, confirm-delete and cancel behavior. The confirmation is visibly destructive and separate from ordinary opening. Backup `never`/`changed` states require action; `current` identifies an actual recorded backup. Sync connection text remains authoritative; neutral `.kf-connection` styling does not claim a verified connection or saved upload. Existing revoke/confirm controls retain their authentication and persistence behavior.

## Spatial relationships and photo tools

A selected object and its inspector use the same action semantics, with a second boundary or label cue. Dimensional fields and authored drawing strokes retain their geometry, dash patterns and context. The required/measured bay comparison and maintenance depth plane retain their exact registered technical palettes. Material front/hardware previews retain their authored colors and textures; separate controls communicate selected state.

Photo annotation fill remains translucent so reference pixels are readable. Reference, included and active rectangles differ in dash pattern and stroke width, with labels preserved. The photo modal uses the photo stack token, dark image wells and a high-contrast light annotation label with dark text stroke. Rendered visibility on bright/dark photos remains a browser requirement; source token adoption does not establish universal image contrast.

## Shared shell and route movement

The main shell owns persistent identity, route navigation and dark structural chrome. Gateway identity uses neutral structure; its enter/resume control uses action semantics. Current navigation has an action edge and underline. Light menu contents nested in the dark header restore light-surface focus. Do not let route focus, drawers or modal overlays sit behind the masthead.

Local canvas layers retain existing relative z-indices. Global drawer/dialog/popover/photo layers use central tokens, preserving the isolated workspace contexts. Verify cross-family navigation with an open chooser, focused control and modal because CSS stacking contexts are not resolved by the static policy.

## Density, RTL and zoom

Field spacing favors separation; studio spacing balances drawing area and controls; factory spacing keeps compact rows around 44px targets; presentation spacing supports customer reading. Logical boundaries and padding follow RTL. Existing physical drawing coordinates, left-edge drawer placement and LTR numeric/photo coordinate contexts remain intentional.

The unsupported device route below 768px remains intact. At 768px and 200% zoom, verify actual wrapping, scrolling, viewport headers and focus visibility. Layout geometry and document overflow require browser evidence rather than a new blanket width override.

## Print and future additions

The main print entry uses `kitchen-design-print.css` through the shell. Standalone reports retain their own embedded stylesheet/export pipeline. Technical drawing lines, material data, totals and decision trace must survive print without screen shadows or dark backgrounds. Do not assume the app stylesheet changes exported HTML.

For a new screen: assign it to an inventory family/wave, consume existing semantic tokens, document its anatomy and actual state hooks, use exact data exceptions only when needed, run source policy and the owning focused checks, then collect the browser matrix. Regenerate inventory only after all source changes stop. Accepted native status must be backed by an explicit QA mechanism; classification and policy checks alone do not grant it.
