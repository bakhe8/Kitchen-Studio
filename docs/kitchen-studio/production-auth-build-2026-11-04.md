## النتيجة

الموقع الذي فُحص: `https://drag-playground-bakheet.bakheet474509.chatgpt.site`، مشروع Sites `appgprj_6ae4e6ee5b5c819181e13977cdcf1c59`. أكدت أدوات Sites أن النسخة المنشورة ٦٨ نُشرت بنجاح في ١ نوفمبر ٢٠٢٦، قبل مراحل فصل السجلات والأدوار والبيانات المحلية. لا يجوز نسبة سلوك المصدر الجديد إلى هذه النسخة القديمة.

أكد المالك أنه لا يملك حسابات اختبار مستقلة، وطلب الاكتفاء بالحساب المتاح وبيان ما يلزم لبقية الأدوار.

## ما ثبت على الخدمة المنشورة

| الفحص | النتيجة الفعلية |
|---|---|
| الدخول من `/signin-with-chatgpt` واختيار حساب المتصفح عبر موفر الهوية | عاد المتصفح إلى خدمة المشاريع، HTTP 200 |
| الخروج من `/signout-with-chatgpt` | HTTP 401 مع شاشة تسجيل الدخول |
| إعادة الدخول بالحساب نفسه | HTTP 200؛ أعيدت الجلسة إلى حالتها المسجلة |
| طلبات بلا جلسة إلى الصفحة والمشاريع والكتالوج والمخزون والورشة | رفضت جميعها بـ401 |
| طلب مجهول بترويسات هوية مصطنعة ودور `owner` | 401؛ لم تُقبل الهوية المصطنعة |
| طلب مورد اختبار غير موجود بحساب مسجل: مشاريع/كتالوج/ورشة | 404 ورسالة خطأ فقط |
| طلب مورد مخزون غير موجود بحساب مسجل | 403 ورسالة خطأ فقط |

لم تُنسخ كلمة مرور أو ملفات جلسة أو مفاتيح وصول. لم يُنشأ أو يُستخدم رمز لتجاوز المصادقة. تُحفظ الأدلة ببيانات وصفية منقّحة؛ لا تتضمن هويات الحسابات أو أجسام مشاريع العملاء أو معاملات رد المصادقة.

عرضت القائمة المتاحة صفر مشاريع. وأكد فحص D1 للقراءة فقط أن جداول المشاريع والمشاركات فارغة، وأن جدول قراء الكتالوج ما زال بالأعمدة القديمة دون عمود الدور. لم يظهر جدول الاعتمادات الجديد في مخطط الإنتاج. مسار `action=session` الجديد غير منفذ في النسخة المنشورة؛ أعاد الشكل القديم لقائمة المشاريع، لا إثبات `subject` الجديد. قد يؤدي GET لقائمة المشاريع القديمة إلى تحديث دليل العضو المسجل؛ لم تُكتب بيانات مشروع أو كتالوج أو مخزون أو أمر ورشة.

نجاح الرفض لا يثبت منح صلاحية إيجابية لدور على مشروع، ولا يثبت قراءة كائن من R2 أو كتابته. لم يُحمّل أرشيف عميل لإجراء فحص سلامة، ولم يُنشأ مشروع إنتاجي للتجربة.

## البناء والإصلاحات المحلية

أُخذت نسخة فعلية مستقلة عن مجلد `node_modules` الحالي وعن بيانات التشغيل والمشاريع. استُخدم `package-lock.json` نفسه، دون تغيير إصدارات الاعتماديات. نجحت أوامر `npm run install:ci` و`npm run typecheck` و`npm run build` بخروج ٠.

شُغّل ناتج Worker المبني محليًا على منفذ اختبار مستقل: نجحت الصفحة الرئيسية و`index.html`، وعادت الأصول الـ٤٢ المعلنة بحالة ٢٠٠ وطابقت بايتات ناتج البناء. رفض API المشاريع الطلب المجهول وملف تعريف ارتباط التطوير التجريبي بـ٤٠١. أُوقفت عملية الاختبار وحدها وتأكد إغلاق المنفذ. هذا تحقق من ناتج الإنتاج محليًا، مستقل عن اختبار حساب ChatGPT على الموقع المنشور.

كشف فحص الأنواع الأول ١٩ تشخيصًا. أُصلحت تصريحات الصادرات الموجودة فعليًا في حزمة المجال؛ بقي إثبات الإفراج الخاص بالمالك اختياريًا لدى مستهلك ختم الرسم حتى لا تُضاف بيانات محجوبة للمصنع. ضُبط نوع بايتات البصمة بما يطابق المخزن الحقيقي، وأصبح مبلغ البيع يتطلب عددًا فعليًا قبل التحويل إلى هللات، فلا يتحول `null` إلى صفر.

أضيف أيضًا رابط دخول إلى شاشة المشروع المشترك عند HTTP 401 فقط، مع مسار عودة محلي مشتق من معرّف المشروع المتحقق منه. بقي الرابط غائبًا عند انقطاع الشبكة ورفض الدور وتعطل الخدمة؛ لم تُمسح المسودة أو النسخة المحلية.

نجحت ستة فحوص تراجع موجهة: رابط الدخول، عميل النطاق، إبطال السعر القديم، استرداد العمليات، معالج المشاريع الفعلي، ومعالج أعمال الورشة. فحص الناتج لم يجد خرائط مصدر أو هويات الدخول المحلية التجريبية أو علامات الاختبارات الخاصة المحددة أو ملفات مفاتيح/بيئة/قواعد بيانات ضمن الحزمة. هذا فحص أنماط محدود، وليس شهادة شاملة بخلو كل تبعية من الثغرات.

نطاق البناء هو اللقطة المختارة عند بدء العمل مع الإصلاحات المحددة أعلاه. تستمر محادثة أخرى في تطوير التركيب والتسليم؛ لا يشمل هذا الادعاء تلقائيًا كل تعديل لاحق منها. يوثق تقرير البناء الملفات المستبعدة وبصماتها.

## ما يلزم لاختبار الأدوار الأخرى فعليًا

1. تثبيت نسخة المصدر المراد إصدارها بعد اكتمال العمل المتزامن، وإعادة البناء عليها، ثم نشرها بإجراء النشر المعتمد.
2. مراجعة ترحيلات قاعدة الإنتاج الإضافية وتطبيقها مع المحافظة على النسخ الحالية؛ النشر وحده لا يكفي لتحديث الأدوار ومخطط السجلات.
3. توفير ثلاثة حسابات اختبار مستقلة للمتجر والمصنع والمندوب، وإتاحة زيارتها للموقع وفق سياسة مشاركة مقصودة. صلاحية دخول الموقع منفصلة عن صلاحية الدور داخل المشروع.
4. إنشاء مشروع اختبار معزول وكتالوج تجريبي، وتعيين الأدوار صراحة من حساب المالك. تُجرى عليه اختبارات القراءة والحفظ ورفض الحقول الأجنبية وتغيير الدور وسحب المشاركة وقراءة R2 وكتابته وإعادة المحاولة، دون استخدام مشاريع العملاء.
