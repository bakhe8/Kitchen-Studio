# التركيب والتسليم — عقد التفاعل والتكامل

المسار الفعلي: `tracking`، بعنوان «التركيب والتسليم»، ضمن بوابة المصنع. يبقى الوصول إليه متاحًا من أوامر التنفيذ الصادرة في مساحة التصنيع، ومن دليل المشروع. جاهزية الموقع لها رابطها في المجموعة نفسها.

## الكائنات ومصدر الحقيقة

مشروع الفريق ← إيصال تصنيع صادر ← وحدة ضمن نطاق الإيصال ← فحوص اسمية وملاحظات ومحاضر تنفيذ. يستخرج الخادم الوحدات من الأرشيف الذي تطابق بصمته إيصال الإصدار؛ المشروع المحلي المفتوح ليس مصدر هذا العرض.

الرسم مخطط جسم متناسب من أبعاد `width/height/depth` الواردة في فحوص الإيصال. لا يخمّن الأبواب أو الخامات أو الجدار. ارتفاع الجسم الوارد محسوب أصلًا؛ لا يُخصم خلوص الأرجل مرتين. الوحدات غير القياسية والقوالب ذات البيانات غير الكافية تظهر كبطاقات فحص وروابط القوالب المتاحة بدل اختراع هندسة.

## آلة الحالة

| الحالة المثبتة | الفعل | الحالة التالية | القاعدة |
|---|---|---|---|
| issued | plan | planned | المالك، مرجع وسماحات صحيحة لكل فحص |
| planned | qc | passed أو planned | قراءات فعلية؛ الفشل يبقى حدثًا محفوظًا ويمنع التغليف |
| passed | pack | packed | جاهزية الشحن الحالية ومحضر التغليف |
| packed | install | installed | جاهزية التركيب، موقع ومحضر، ولا ملاحظات مانعة مفتوحة |
| installed | accept | accepted | المالك، اسم العميل ومحضر الاستلام، ولا ملاحظات مانعة مفتوحة |
| packed أو installed | observe | الحالة نفسها | ملاحظة مشتركة مرتبطة بهذه الوحدة وموضع صالح |
| packed أو installed | resolve | الحالة نفسها | ملاحظة مفتوحة لهذه الوحدة ونتيجة معالجة؛ حدث جديد |
| accepted | — | accepted | سجل للقراءة؛ لا إعادة كتابة للمحاضر |

الاستلام هو توثيق المالك لاستلام العميل، وفق آلية المشروع الحالية. ليس توقيعًا إلكترونيًا مصادقًا عليه من حساب العميل.

## دورة التفاعل

| المحفز | فعل المستخدم | القواعد | الاستجابة والحالة المستقرة |
|---|---|---|---|
| اختيار إيصال ووحدة | زر الوحدة أو المحدد | نطاق الإيصال والدور مؤكّدان من API | رسم وفحوص وسجل الوحدة المختارة |
| اختيار قياس | نقر خط الرسم أو زر الفحص؛ لوحة المفاتيح متاحة | القيمة الاسمية ثابتة | تمييز البعد وتركيز القراءة السياقية |
| تحرير قراءة | إدخال رقمي عربي أو لاتيني | لا تحويل للفراغ إلى صفر؛ الحدود وسماحات العدد محفوظة | قراءة وفرق ومطابقة فورية دون تعديل أبعاد الإيصال |
| إضافة ملاحظة | نقر الجسم أو زر موضع المنتصف أو اختيار فحص | نسب 0..1 من أعلى يسار الجسم، أو مفتاح فحص صالح | دبوس مسودة وسبب الملاحظة وأثرها؛ لا كتابة تلقائية في الورشة |
| حفظ المسودة | زر صريح | هوية الحساب والمشروع والإيصال والوحدة والفعل؛ هدف المعالجة مستقل | نسخة محلية قابلة للاستعادة، بلا حدث تنفيذ |
| تراجع/إعادة | أدوات المسودة | العمليات غير المرسلة فقط | استعادة النص الخام والموضع؛ لا استدعاء API |
| تسجيل | زر محضر المرحلة/الملاحظة | تحقق كامل، تسلسل متوقع، دور حالي، وهوية الحساب | قفل المحاولة ثم إقرار الحدث وتحديث السجل |
| انقطاع الرد | إعادة المحاولة بالطلب نفسه | نفس المعرف ونفس الجسم؛ الحقول مقفلة | حدث واحد حتى لو كان الطلب الأول قد حُفظ |
| نجاح الحفظ وفشل التحديث | تحديث السجل بعد الحفظ | لا إعادة POST لحدث مُقرّ به | استعادة العرض من GET مع بقاء الإقرار ظاهرًا |
| تعارض أو تبدّل الحساب | تحديث المصدر | لا إعادة تأسيس لمسودة حقيقية تلقائيًا | مسودة قديمة مقفلة أو إخفاء السجل عند فقد الصلاحية |
| معالجة ملاحظة | اختيار الملاحظة وكتابة نتيجة التصحيح | مسودة مستقلة لكل ملاحظة، لا استبدال نص قديم | حدث معالجة، زوال المنع عند إغلاق آخر ملاحظة مانعة |

حلقة العمل: معاينة ← ملاحظة ← تصحيح ← إعادة فحص ← توثيق المعالجة ← تركيب/استلام. تبقى الملاحظة الأصلية ونتيجة المعالجة في السجل. لا يؤدي التراجع عن المشروع المحلي إلى حذف محاضر الورشة.

## الحفظ والحدود

مسودات التنفيذ في مساحة تخزين محلية مستقلة عن مسودات المشروع. المفتاح يضم الحساب والمشروع السحابي والإيصال والوحدة والفعل، ويضم معرّف الملاحظة لمسودة المعالجة. يحمل المحتوى إصدار الإيصال وتسلسل الوحدة والنصوص الخام وموضع الملاحظة ومحاولة الإرسال المجمدة. حفظ المسودة لا يعني أنها محفوظة على أجهزة الفريق.

يحمي حارس التنقل تغييرات الوحدة والإيصال والصفحة. تحفظ المسودة قبل الإرسال لضمان استعادة معرّف المحاولة؛ فشل التخزين يمنع إرسال طلب لا يمكن استعادته. المسودة الفارغة التي لم تُحرّر يمكن أن تتبع التسلسل الجديد، بينما تبقى المسودة الفعلية القديمة مقفلة حتى المراجعة والإلغاء الصريح.

API يعيد `subject`، والواجهة ترسله في `X-Studio-Subject`. يرفض الخادم اختلافه عن الحساب الحالي قبل الكتابة أو إعادة الطلب. تُحفظ قواعد العضوية والتسلسل والإيصال وجاهزية آخر إصدار كما كانت. الملاحظات الفنية الجديدة ونتائج معالجتها مشتركة مع المصنع؛ نصوص المحاضر الخاصة السابقة واسم العميل والموقع واسم المنفذ تبقى محجوبة عن إسقاط المصنع.

## العرض والتحقق

ثلاثة أعمدة على الحاسوب، شريط وحدات ثم رسم ومفتش على اللوحي، ومحتوى مكدس على الهاتف. أدوات السياق في صف مستقل أسفل الرسم حتى لا تغطي القياسات. التحديد والموضع وحالة المنع لها نصوص وحالات تركيز، ولا تعتمد على اللون وحده.
